# My Todo

เว็บรายการสิ่งที่ต้องทำ (Todo) แบบง่าย ๆ — เพิ่ม, ติ๊กว่าเสร็จ, และลบรายการได้
ข้อมูลเก็บไว้ในเบราว์เซอร์ (localStorage) ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล

## รันบนเครื่อง

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย หรือ

```bash
npx serve .
```

## Deploy ขึ้น Vercel

1. ไปที่ https://vercel.com/new แล้วเลือก import repo `my-todo`
2. Framework Preset เลือก **Other** (ไม่ต้องตั้ง build command)
3. กด **Deploy**
